# 10. 일반 사용자 관점 개선 백로그 (2026-08-04)

> 실제 화면·데이터·사용자 여정을 근거로 뽑은 개선 목록. UX 재구성(docs/09)·리뷰(docs/07) 이후 "다음에 뭘 할까"의 기준.
> 우선순위: **P0=임팩트 큼/자주 겪음**, P1=가치 있음, P2=여유될 때. 노력(S/M/L) 병기.

---

## 진단 요약 (근거)

- **카드가 전부 텍스트+이모지** — `data.json`에 사진 필드 없음. 발견 앱의 핵심인 "먹음직스러움"이 화면에 없음. → 가장 큰 공백.
- **온보딩 부재** — "노포/야장"이 뭔지, 상단 토글이 뭘 바꾸는지 신규 사용자가 모름.
- **검색이 단순** — 이름·메뉴 문자열 매칭만. 최근검색·추천·메뉴 카테고리 원탭 없음.
- **안 쓰는 데이터** — `리뷰수`(신뢰도), `휴무일`(오늘 쉼 표시), `정보검증일`(신선도) 모두 미노출.
- **발견 피드 미완** — "지역별로 둘러보기"(구 칩) 레일이 기획(docs/09 B.5)에 있으나 미구현.

## P0 — 사용자가 매번 마주치고, 인상을 좌우

### 10.1 발견 피드·카드에 사진 (M~L)
문제: 카드가 텍스트라 "발견하는 재미"가 약함. 
- **10.1a (M)** — ✅ 완료 2026-08-05. **리뷰 사진 재활용**: `useCommunityRatings`가 key별 대표 사진 1장(최신 리뷰)을 함께 집계 → 카드 상단 커버·레일 썸네일로 표시. "사진 있는 집" 레일(≥3장일 때 발견 피드 최상단). prop 추가 없이 기존 `community` 엔트리에 `photo` 실어 연결. *콜드스타트: 사진 쌓일수록 커버·레일 자연 증가.*
- **10.1b (L)** — **크롤러 대표사진 수집**: 카카오맵 상세의 대표 이미지 URL을 크롤해 `photo_url` 필드 추가. 커버리지 즉시 100%. *리스크: 핫링킹/ToS·이미지 안정성 검토 필요. 별도 스파이크.*
- 권장: 10.1a 먼저(안전·저비용) → 데이터 쌓이며 자연 개선, 10.1b는 스파이크 후 결정.

### 10.2 첫 방문 온보딩 (S) — ✅ 완료 2026-08-05
- 최초 1회 웰컴 카드(`Onboarding.jsx`): 노포/야장 뜻 + 하단 탭·AI 사용법 3단계. `nopo-onboarded` localStorage로 1회성. 코치마크 대신 단일 카드(레이아웃 무관·견고).

### 10.3 "오늘" 영업 정보 강화 (S~M) — ✅ 완료 2026-08-05
- `isClosedToday`(영업시간 오늘 값=='closed') 헬퍼 → 카드/모달에서 **"오늘 휴무"**(중립 회색)를 "영업종료"(빨강)와 구분 표시.
- 모달 영업시간 표는 오늘 요일 행 강조(기존) 유지.

## P1 — 가치 있는 개선

### 10.4 검색 경험 (M) — ✅ 완료 2026-08-05
- 검색창 포커스(빈 상태) 시 제안 패널: **최근 검색어**(localStorage, ×·지우기) + **메뉴로 찾기 칩**(국밥·곱창·삼겹살·해장국·칼국수·냉면·파전·족발·보쌈·순대·노가리·백반) 원탭 검색.
- 최근 검색어 기록: 메뉴칩 선택 / Enter / 검색 중 결과 열기 시. 8개 상한.
- (후속) 빈 결과 화면 추천 검색어는 미구현.

### 10.5 지역별로 둘러보기 레일 (S~M) — ✅ 완료 2026-08-05
- 발견 피드에 구(區) 칩(식당 수 많은 순 25개) → 탭하면 그 지역으로 필터(browsing 그리드 전환, 기존 필터칩으로 해제). docs/09 B.5 조각 완성.

### 10.6 지도 "이 지역 검색" (M) — ✅ 완료 2026-08-05
- 지도를 사용자가 움직이면 "이 지역 재검색" 버튼 노출 → 탭하면 현재 뷰포트(`map.getBounds`) 안 식당만 하단 시트에. "전체 보기"로 해제, 필터 변경 시 자동 해제.
- 프로그램적 이동(fitBounds·flyTo)은 타임아웃 기반 `programmaticRef`로 버튼 억제(moveend 발생 여부에 비의존 — 견고).

### 10.7 리뷰 신뢰·상호작용 (M) — ✅ 완료 2026-08-06
- 카드에 `리뷰수`(카카오) "리뷰 N" 배지. 커뮤니티 리뷰 "사진순" 정렬.
- **도움돼요/신고**: `review_reactions` 테이블(helpful/report 통합). 도움돼요 토글·신고 1회, 테이블 미설정 시 자동 비활성. 셋업 SQL은 docs/07 §7.11.
- ⏳ **실기기 end-to-end 검증 보류(2026-08-07)**: 테이블·RLS 3정책(insert/delete own, read all=public) 모두 확인 완료. 다만 도움돼요 저장/표시 최종 확인은 **다른 계정으로 재테스트** 필요(1인 토글로는 순증 0 판별이 어려움). 완전 새로고침 후 회색→탭→활성/1 흐름으로 확인 예정.
