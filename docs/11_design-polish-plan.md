# 11. 디자인 폴리시 계획 (디자이너 협의 결과, 2026-08-10)

> ui-ux-pro-max 스킬 + 시니어 프로덕트 디자이너 관점으로 실화면 9종(모바일 발견/레일/그리드/모달/지도/리스트/AI/야장 + 데스크톱 1280px)을 감사. "개발자가 만든 느낌"을 줄이는 고레버리지 개선 위주로 우선순위화.
> 정체성(듀얼톤·세리프·이모지)은 유지. 레이아웃 규율·간격 리듬·데스크톱 반응형이 핵심 개선축.

---

## P0 — 신뢰도 직결(가장 "미완성"으로 읽히는 것)

- **11.1 데스크톱이 늘어난 폰 (Screen 09)** — 1200px에서 헤더·AI배너·히어로가 전체폭 단일 컬럼. `--max-width` 축소 + 콘텐츠 중앙 정렬 강화, `전체` 그리드는 auto-fill 다열(이미 minmax 300px), **하단 탭을 데스크톱에서 중앙 정렬 플로팅 바**로(전체폭 바 = 가장 큰 "폰 앱" 신호). 이상적으론 좌측 사이드 내비. **L**
- **11.2 모달 위치 지도 빈 박스 (Screen 04)** — `위치` 섹션 iframe이 빈 사각형으로 보임(헤드리스 미로드일 수 있음 → 실기기 확인). 최소한 로딩 플레이스홀더(핀 아이콘+주소) + `border-radius:12px`. **S~M**
- **11.3 AI 배너 존재감 (Screen 01/08)** — 일급 기능인데 배경과 잘 안 구분. 대비↑(accent 테두리·그라데이션), 우측 "물어보기 →" 칩, 라벨 accent 색. (이전에 일부 반영됨 — 대비 재점검) **S**

## P1 — 아마추어/프로 격차를 좁히는 폴리시

- **11.4 카드 그리드 리듬 (Screen 02/03)** — 카드 테두리가 옅어 배경에 묻힘, 레일 간 세로 간격 불균일, 메타(구·평점) 베이스라인 정렬. 카드 테두리/라운드/패딩 표준화, 섹션 간격 32px 통일. **M**
- **11.5 검색+필터+위치 툴바 (Screen 01~03/06)** — 4줄로 흩어진 기본 입력. 하나의 툴바로: 검색(내장 아이콘)+위치/필터 pill 칩+결과 수는 작은 캡션. **M**
- **11.6 설치 배너 상시 노출** — 모든 화면 상단 ~48px 점유. 더 슬림·저대비, 데스크톱에선 숨김. **S**
- **11.7 히어로 카드 위상 (Screen 01)** — 일반 카드와 무게 비슷. 이미지 전면·세리프 28~32px·하단 스크림(사진 있을 때). 플로팅 원형 버튼 의미 불명확 → 명확한 아이콘/툴팁. **M** (사진 콜드스타트 의존)
- **11.8 지도 시트 헤더 (Screen 05)** — "491곳" 중앙 여백. 좌측 정렬 + 정렬 컨트롤. 플로팅 FAB 화면 간 일관화. **S~M**

## P2 — 마감 다듬기

- **11.9 AI 패널 (Screen 07)** — 모델 버전 문자열("Gemini 3.6 Flash") 노출 제거(소비자 대상 부적절), 제안 칩 2열, 아이콘 정리. **S**
- **11.10 빈 상태 (Screen 06)** — 세그먼트 채운 active, 큰 일러스트 + 보조 CTA("맛집 둘러보기 →"), 세로 중앙 정렬. **S**
- **11.11 타이포 스케일 압축** — 섹션 헤딩(세리프 20/600) vs 카드 타이틀(15~16/600) vs 메타(12~13/muted) 계층 명확화. **M**
- **11.12 대비 AA 감사** — muted 회색(구명·배너 subtext·결과 수), 토글 비활성, 야장 민트 텍스트 4.5:1 재점검. **S**

## 실행 순서
1. **11.1 데스크톱 + 11.9 AI 패널** (이번 배치) — 가장 큰 "미완성" 인상 제거 + 즉효 정리.
2. 11.3 AI 배너 대비 · 11.4 카드 · 11.5 툴바 — 최다 노출 표면.
3. 11.2 모달 지도(실기기 확인 후) · 11.6~11.8 · P2.

## 진행 상태
- ✅ **11.1 데스크톱 폴리시(부분, 2026-08-10)**: `--max-width` 1200→960(피드 밀도↑), 하단 탭을 데스크톱(≥900px)에서 520px 중앙 플로팅 바로, 지도 시트도 중앙 폭 정렬. *남은 이상형: 좌측 사이드 내비 + 지도 2-pane(별도 L 작업).*
- ✅ **11.9 AI 패널(2026-08-10)**: 모델 버전 문자열 제거 → "노포지도 데이터로 골라드려요".
- ✅ **11.4 카드 리듬(2026-08-10)**: 카드 경계 대비↑(먹먹함 해소, 듀얼톤), hover 시 accent 테두리, 푸터 메타 `flex-wrap`+평점 좌측 고정으로 배지 cram 방지.
- ✅ **11.5 검색 툴바(2026-08-10)**: 검색창에 리딩 돋보기 아이콘 + placeholder 대비 보정.
- ✅ **11.11 타이포 스케일(2026-08-10)**: 섹션 헤딩이 카드 타이틀보다 작던 역전 해소. 스케일 = 히어로(2.5/1.9) > 섹션·레일 헤딩(1.4) > 카드 타이틀(1.25/1.15) > 레일 카드(1.02) > 메타(0.75). 레일 헤딩에 letter-spacing 추가.
- ✅ **11.6 설치배너 슬림(2026-08-10)**: 패딩·폰트·대비 축소, 데스크톱(≥900px) 숨김.
- ✅ **11.10 빈 상태(2026-08-10)**: 내 리스트 빈 화면에 큰 아이콘 + "맛집 둘러보기 →" CTA(발견 탭 이동) + 세로 중앙 정렬.
- ✅ **11.12 대비 AA(2026-08-10)**: 야장 `--text-secondary` #7A7090(4.0~4.2:1 미달)→ #9A8FB2(6.1~6.5:1). 노포 secondary는 이미 5.3+로 통과라 유지.
- ✅ **11.3 AI 배너(2026-08-10)**: 그라데이션·글로우 강화, 타이틀 accent 색, 우측 화살표 → 채운 "물어보기 →" CTA 칩.
- ✅ **11.7 히어로(2026-08-10, 부분)**: accent 틴트 그라데이션 + accent 테두리 + 그림자로 일반 카드와 구분되는 프리미엄 표면. *이미지 전면형은 사진 콜드스타트로 보류.*
- ✅ **11.8 지도 시트 헤더(2026-08-10)**: "N곳" 좌측 정렬(중앙 여백 해소).
- ✅ **11.2 모달 위치 지도(2026-08-10)**: 실기기 확인 결과 **정상 렌더 — 헤드리스 캡처만의 오탐**이었음(iframe 미로드). 수정 불필요.
- ✅ **데스크톱 완성형(2026-08-10)**: ≥1024px에서 하단 탭 → 좌측 세로 사이드바(88px, active 좌측 accent 인디케이터), 지도 탭은 하단 시트 오버레이 → **좌측 리스트 레일(380px) + 지도 2-pane**. 태블릿(900~1023)은 중앙 플로팅 바 유지, 모바일(<900) 무영향. 실측: 사이드바 88 + 레일 380 + 지도 972.
