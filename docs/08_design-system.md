# 8. 디자인 개선 체계 (Design System & Review Process)

> 목적: 디자이너·개발자가 **일관된 기준**으로 노포지도 UI를 개선·검수할 수 있는 단일 체계.
> 엔진: `ui-ux-pro-max` 스킬(로컬 디자인 지능 DB)을 **의사결정·검수 도구**로 사용.
> 작성 2026-07-31.

이 문서는 3가지로 구성된다: ① 디자인 지능 엔진 사용법(스킬) ② 노포지도 디자인 토큰(단일 기준) ③ 우선순위 리뷰 체크리스트 & 프로세스.

---

## 8.1 디자인 지능 엔진 — `ui-ux-pro-max` 스킬

디자인 결정이 필요할 때 추측하지 말고 **스킬 DB를 조회**한다 (84 스타일·192 팔레트·74 폰트페어·98 UX 가이드·아이콘·GSAP 모션·차트).

```bash
SK="$HOME/.claude/plugins/cache/ui-ux-pro-max-skill/ui-ux-pro-max/2.11.0/.claude/skills/ui-ux-pro-max"

# 전체 디자인 시스템 추천 (신규 페이지/제품)
python3 "$SK/scripts/search.py" "<제품유형 키워드>" --design-system -p "노포지도"

# 도메인별 상세 조회
python3 "$SK/scripts/search.py" "<질의>" --domain ux          # 접근성·터치·폼·네비 가이드
python3 "$SK/scripts/search.py" "<질의>" --domain style       # 스타일
python3 "$SK/scripts/search.py" "<질의>" --domain color       # 팔레트
python3 "$SK/scripts/search.py" "<질의>" --domain typography  # 폰트 페어
python3 "$SK/scripts/search.py" "<질의>" --domain icon        # 아이콘 세트
python3 "$SK/scripts/search.py" "<질의>" --domain gsap        # 모션 프리셋
```

> ⚠️ 스킬은 **일반 추천 엔진**이다. 노포지도는 이미 확립한 **듀얼톤 브랜드 정체성**(8.2)이 있으므로, 스킬이 제안하는 팔레트/폰트를 통째로 교체하지 않는다. 스킬은 **① 놓친 원칙 발견 ② 개별 결정 근거 ③ 검수 체크리스트**에 쓴다. 정체성은 8.2가 기준.

## 8.2 노포지도 디자인 토큰 (Source of Truth)

**실제 정의 위치**: `frontend/src/index.css` — `:root`(노포) / `.yajang-theme`(야장). 코드가 진짜 기준이고, 아래는 그 요약.

### 듀얼톤 아이덴티티
| | 노포 (`:root`) | 야장 (`.yajang-theme`) |
|---|---|---|
| 컨셉 | 따뜻한 빈티지 (세월·정겨움) | 밤거리 네온 (포차 감성) |
| bg-primary | `#1C1510` 크래프트 브라운 | `#0D0A1A` 미드나잇 퍼플 |
| text-primary | `#F0E8DC` 크림 | `#E0D8F0` 쿨 화이트 |
| text-secondary | `#9C8D7A` (4.6:1 AA) | `#7A7090` (4.6:1 AA) |
| **accent** | `#C8964A` 앰버 골드 (5.1:1) | `#3DFFC8` 네온 민트 (7.2:1) |
| text-on-accent | `#1C1510` (앰버 위 5.06:1) | `#0D0A1A` (민트 위 17.3:1) |
| display 폰트 | Noto Serif KR | Pretendard 800 |

- 본문 폰트: **Pretendard** / 제목: `--font-display`
- **4색 역할 규칙** (이 외 색 남발 금지): 로즈/accent = 액션·필터 · 초록 `#22c55e` = 영업중·방문 · 빨강 `#ef4444` = 종료·경고 · 골드 `#fbbf24` = 별점. **제네릭 로즈(#f43f5e)는 폐기됨.**
- accent 배경 버튼 글자색은 **반드시 `--text-on-accent`** (밝은 민트/앰버 위 흰 글자는 대비 미달 → 금지).
- 질감: 노포 종이 그레인 / 야장 네온 글로우 (전부 CSS, `pointer-events:none`).

## 8.3 우선순위 리뷰 체크리스트

스킬의 우선순위(1→10)를 노포지도에 적용. **디자인 변경 시 이 순서로 검수**. 현재 상태 표기: ✅ 충족 / ⚠️ 개선 여지 / ❌ 부채.

| # | 항목 (CRITICAL→LOW) | 노포지도 상태 |
|---|---------------------|---------------|
| 1 | **접근성**: 대비 4.5:1, aria-label, 키보드 내비, 포커스 링 | ✅ AA 대비·모달 포커스 트랩·aria 적용 |
| 2 | **터치/인터랙션**: 44×44px, 8px 간격, 로딩 피드백, hover 의존 금지 | ✅ 터치타깃 44px·스켈레톤·카드힌트 hover 비의존 |
| 3 | **성능/CLS**: WebP/AVIF, lazy, 공간 예약 | ⚠️ og.png/PNG 다수 → WebP 검토, 지도 lazy는 됨 |
| 4 | **스타일 일관성 + 아이콘**: 제품유형 매칭, **SVG 아이콘(이모지 금지)** | ✅ UI 컨트롤 이모지 → SVG(`components/icons.jsx`). 음식 카테고리·브랜드 탭 이모지는 정체성으로 유지 |
| 5 | **레이아웃/반응형**: mobile-first, viewport, 가로스크롤 금지 | ✅ 375/768/1024/1440 대응, 가로스크롤 없음 |
| 6 | **타이포/컬러**: 본문 16px, line-height 1.5, 시맨틱 토큰 | ✅ 토큰 시스템(8.2), 원시 hex 최소화 |
| 7 | **애니메이션**: 150–300ms, 의미 전달, reduced-motion | ✅ 테마별 타이밍·`prefers-reduced-motion` |
| 8 | **폼/피드백**: 가시 라벨, 필드 옆 에러, 헬퍼 | ✅ 리뷰/검색 라벨·글자수·빈상태 |
| 9 | **내비게이션**: 예측가능 back, 딥링크 | ✅ `?r=`·`?share=` 딥링크, URL 동기화 |
| 10 | **차트/데이터** | N/A (차트 없음) |

### 스킬 공통 Pre-Delivery 체크 (매 배포 전)
- [x] 이모지를 아이콘으로 쓰지 않음 — UI 컨트롤 SVG화 완료 (카테고리 음식 이모지는 브랜드로 유지)
- [ ] 클릭 요소에 `cursor: pointer`
- [ ] hover 전환 150–300ms
- [ ] 대비 4.5:1 이상 (라이트/다크 모두)
- [ ] 키보드 포커스 가시
- [ ] `prefers-reduced-motion` 존중
- [ ] 375/768/1024/1440 반응형 확인

## 8.4 디자인 리뷰 프로세스 (매 디자인 변경마다)

1. **조회**: 관련 결정을 스킬로 질의 (`--domain ux/style/color/icon…`). 근거 없는 취향 결정 금지.
2. **기준 대조**: 8.2 토큰·4색 규칙을 벗어나지 않는지 확인. 새 색/폰트는 8.2에 먼저 반영.
3. **체크리스트**: 8.3 우선순위 1→10 순으로 검수(특히 1~4 CRITICAL/HIGH).
4. **구현**: `frontend/src/index.css`(토큰·스타일) + 컴포넌트. lint 0 / build 통과.
5. **검증**: Selenium 스크린샷으로 **노포·야장 양 테마 + 데스크톱/모바일** 확인. 인터랙션 회귀 없는지.
6. **기록**: 큰 변경은 `docs/06`에 세션 로그, 이 문서(8.3 상태표)도 갱신.

## 8.5 현재 진단 & 개선 백로그 (첫 적용 결과)

스킬 검수 결과, 대부분의 원칙(접근성·터치·반응형·모션·타이포)은 **이미 충족**(그간의 디클러터·듀얼톤 작업 성과). 남은 개선점:

### 🔴 우선 — 이모지 아이콘 → SVG 아이콘 (스킬 4번 안티패턴)
- 현재: 카테고리(🍜🍖🐟…), 방문(○/✓), 즐겨찾기(♡/♥), 랜덤(🎲), 챗봇(🗨🤖), 배지(💬🟢) 등을 **이모지로 아이콘 처리**.
- 문제: 이모지는 플랫폼별 렌더 편차·플레이스홀더 느낌·정렬/색 제어 불가. 스킬은 **일관된 SVG 아이콘(Heroicons/Lucide)** 권장.
- 방향: **UI 컨트롤 아이콘**(방문/즐겨찾기/랜덤/뷰토글/닫기 등)을 라인 SVG로 교체하고 accent 색 상속. **음식 카테고리 이모지**는 브랜드 개성이라 유지 검토(선택). 큰 작업이라 별도 진행.

### 🟡 성능 — 이미지 포맷
- `og.png`·아이콘 PNG → WebP 검토(CLS·용량). 우선순위 낮음.

### 다음 액션
위 "이모지 → SVG 아이콘" 교체를 별도 작업으로 진행하면 스킬 4번 부채가 해소된다. (범위: UI 컨트롤 우선, 카테고리 이모지는 선택)
